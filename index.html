한영 자동전환

입력칸을 누르면 한글로 쓸 칸인지 영문으로 쓸 칸인지 판단해서 한/영을 자동으로 바꿔 줘요.

확장 프로그램만으로는 한/영을 바꿀 수 없어요.
브라우저는 보안상 컴퓨터의 입력기를 직접 바꿀 수 없어서, 작은 도우미 프로그램을 한 번 설치해야 해요.

1. 도우미 내려받기

윈도우
윈도우 10, 11 · Microsoft 한국어 입력기
윈도우용 내려받기
맥
macOS 12 이상 · 인텔, 애플실리콘
맥용 내려받기

2. 설치하기

윈도우

  1. 내려받은 압축을 풀어요.
  2. install.bat을 더블클릭해요. 파란 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행을 눌러요.
  3. 브라우저를 완전히 껐다 켜요.

맥

  1. 내려받은 압축을 풀어요.
  2. 터미널을 열고 bash 와 한 칸 띄어 쓴 뒤, install.command 파일을 터미널 창에 끌어다 놓고 엔터를 눌러요.
  3. 브라우저를 ⌘Q로 완전히 껐다 켜요.

확장 프로그램 아이콘을 눌러 도우미 연결됨이 보이면 끝이에요.

쓰는 법

  • 칸을 누르면 자동으로 한/영이 바뀌고, 칸 오른쪽에 한 또는 A 표시가 잠깐 떠요.
  • 판단이 틀리면 그 칸에서 한/영 키로 바꾸세요. 다음부터 그 칸은 기억해요.
  • 팝업에서 사이트별로 끄거나, 판단이 어려운 칸의 기본값을 정할 수 있어요.

문제 해결

  • 도우미가 연결되지 않았어요: 설치 파일을 다시 실행하고 브라우저를 완전히 껐다 켜 주세요.
  • 윈도우에서 칸을 눌러도 안 바뀌어요: 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션 → Microsoft 입력기 → 키보드 옵션 → 호환성에서 '이전 버전의 Microsoft IME 사용'을 켜 보세요.
  • 도우미 지우기: 압축 안의 uninstall 파일을 실행하세요.
