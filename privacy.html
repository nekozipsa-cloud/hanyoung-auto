개인정보 처리방침

한영 자동전환 (Chrome 확장 프로그램과 도우미 프로그램) · 시행일 2026년 11월 20일

요약

한영 자동전환은 개인정보를 수집하지 않고, 어떤 정보도 외부 서버로 보내지 않아요. 모든 처리는 사용자의 컴퓨터 안에서만 이뤄져요.

확장 프로그램이 보는 정보

입력칸을 누르면 그 칸이 한글 칸인지 영문 칸인지 판단하기 위해 다음 정보만 확인해요.

  • 칸의 종류(이메일, 비밀번호, 검색 등)와 개발자가 붙인 이름(name, id)
  • 칸의 이름표, 안내 문구, 칸 바로 옆의 짧은 글자
  • 지금 보고 있는 사이트의 주소 중 도메인 이름(예: example.com)

사용자가 칸에 입력한 내용은 읽지 않아요. 비밀번호 칸은 판단 대상에서도 빼요.

저장하는 정보

사용자가 어떤 칸에서 한/영을 직접 바꾸면, 다음에 같은 칸에서 똑같이 바꿔 주려고 아래 내용을 브라우저 안(chrome.storage.local)에 저장해요.

  • 사이트 도메인 이름, 칸을 구분하는 정보(칸 종류, 이름, 이름표), 고른 입력 언어(한글/영문), 저장 시각
  • 사용자가 고른 설정(켜기/끄기, 사이트별 끄기, 기본값, 표시 방식)

이 정보는 사용자의 브라우저에만 있고, 개발자를 포함한 누구에게도 전송되지 않아요. 확장 팝업에서 언제든 지울 수 있고, 확장 프로그램을 삭제하면 함께 지워져요.

도우미 프로그램

도우미 프로그램은 확장 프로그램이 보낸 "한글로" 또는 "영문으로" 요청에 따라 컴퓨터의 입력기만 바꿔요. 사용자가 한/영 키를 누르면 바뀐 입력 언어를 확장 프로그램에 알려 줘요. 키 입력 내용은 기록하지 않고, 인터넷에 연결하지 않아요. 문제 확인용으로 전환 기록(시각, 한글/영문)만 사용자 컴퓨터의 로그 파일에 남겨요.

제3자 제공

수집하는 개인정보가 없으므로 제3자에게 제공하거나 판매하지 않아요. 광고나 분석 도구도 쓰지 않아요.

Privacy Policy (English)

HanYoung Auto does not collect, transmit, sell, or share any personal data. To decide whether a text field should be typed in Korean or English, the extension reads only the field's type, attributes (name, id), label, placeholder and nearby short text, and the domain of the current site. It never reads what the user types, and it ignores password fields. When the user manually switches the input language in a field, the domain, a field identifier, and the chosen language are saved locally in chrome.storage.local so the extension can repeat that choice next time. This data never leaves the user's browser and can be deleted from the popup at any time. The companion helper program only switches the operating system's input method on request from the extension and reports manual changes back to it; it does not log keystrokes and makes no network connections.
